# Thrive Companion

A private, personal Thrive learning and reflection app starter.

## What's included
- Responsive dashboard and navigation
- Programme chapter library with completion tracking
- Exercise prompt and answer capture
- Journal and reflection entries
- Belief exploration workspace
- Personal toolkit
- Progress snapshot
- JSON export/import backup

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server or GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `thrive-companion`).
2. Upload the contents of this folder (not the outer ZIP).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub to provide the site address.

## Privacy and important limitations
This starter stores entries in browser localStorage on the device/browser being used. Entries are not sent to GitHub, but they do not automatically sync between devices and can be lost if browser site data is cleared. Use Settings & backup to export JSON backups regularly and keep them somewhere private. Do not treat this as encrypted storage for highly sensitive information.

The app is a starter, not a production account-based cloud service. Cross-device sync, sign-in, encryption at rest, automated backup and more advanced chapter/lesson editing can be added in a later version.

Thrive course content is not preloaded. Add only material you are entitled to store and use.
